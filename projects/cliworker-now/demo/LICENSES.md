此文件由 `tools/demos/cliworker-now/build.mjs` 生成：构建时逐个核对 `package.json` 的 license 字段，未在允许列表（MIT、BSD-3-Clause、BSD-2-Clause、ISC、Apache-2.0、CC0-1.0）内的包会使构建失败而不会被打包。

- **CLI Worker Now 插件**（dsh-cliworker-now@0.8.4，MIT）：`app.js` 中的面板、设置、预设、模型与权限菜单等组件及注入样式直接取自插件 `src/client` 与 `src/shared`，内嵌的各 CLI 图标为插件 `src/client/assets` 的缩小副本。

- 图标中出现的 DeepSeek、Codex、Claude Code 等名称与标识属于各自权利人；许可证只覆盖代码，不授予商标权。
