Overview

项目简介

上市公司年报里的三大报表散落在 PDF 的不同页码上，同一个科目在不同公司的叫法和披露口径也不完全一致。直接拿原文算比率，口径难统一；全部归并成标准科目，又不容易回到原文核对。

我本硕都读会计学，这个项目是把财务分析口径落到产品规则上的一次尝试：系统支持 PDF、Excel、巨潮资讯 3 种来源导入三大报表，原文披露数据与标准会计科目分两层存储，计算 4 类 13 项财务比率，并为不同读者设计 3 类视图。归母与合并口径怎么取、缺失时怎么回退，都写成了明确的规则。

我负责需求定义、口径与流程设计和测试验收，组织 AI Agent 协作完成开发。后端用 FastAPI + SQLite，前端用 Vue3 + Element Plus + ECharts，单机本地运行。

  1. 01年报来源PDF · Excel · 巨潮资讯
  2. 02原文披露层保留原文科目、金额与页码
  3. 03映射规则自动映射 + 人工复核边界
  4. 04标准科目层统一口径的三大报表
  5. 05比率与视图4 类 13 项比率 · 3 类视图

          What I did

          我做了什么

          • 数据建模：把年报原文披露数据与标准会计科目分两层存储，用页码和映射规则把来源与指标关联起来，既能统一口径，也能回到原文复核；在此基础上计算偿债、盈利、营运、现金流 4 类 13 项财务比率。
          • 口径落到规则：把归母与合并口径、缺失回退规则写进产品规则，例如 ROE 优先取归母净利润 / 归母所有者权益，缺省时回退为净利润 / 所有者权益合计；对缺失值和零分母保留原因，便于追溯。
          • 导入与复核：支持 PDF、Excel、巨潮资讯 3 种来源导入三大报表，为自动映射设置人工复核边界。用 10 家年报做初检，9 家达到自动导入条件、1 家转人工复核；据此发现续页定位缺陷并调整规则，调整后迈瑞医疗资产负债表映射 46 个字段。
          • 分层呈现：为管理层、投资人和专业人员设计 3 类视图；按报告期匹配去年同期，区分科目金额、同比与结构占比，结合趋势和变动排行定位财务变化。
          • AI Agent 协作开发：由我定义需求、设计口径与流程，组织 AI Agent 协作实现前后端，并负责测试验收。
